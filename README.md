A small program that writes one food picture to `/output/entry.png`:
a thick-cut grilled ribeye, sliced, filling the frame — pink juicy
centre, charred crust, melted herb butter dripping, faint steam, dark
slate behind it. One ingredient, one taste: steak. The photograph is
shipped in the repository (`entry.jpg`, 1024x683 JPEG, 224,861 bytes)
and the program copies it byte for byte — no network, no external
files at run time — so the program is deterministic: two runs write
the same bytes. The program itself uses only the Python standard
library, so it runs in the sandbox exactly as it runs here.

## Run it

```sh
python3 main.py
```
